# HV-SESAME Analyzer

HV-SESAME Analyzer is a standalone MATLAB application for automated SESAME-based quality assessment of Horizontal-to-Vertical Spectral Ratio (HVSR) measurements generated by Geopsy.

## Features

- Imports paired Geopsy `.hv` and `.log` files
- Evaluates SESAME reliability criteria V1–V3
- Evaluates SESAME clear-peak criteria V4–V9
- Computes Reliability Score, Clear-Peak Score, and Quality Score
- Classifies measurements as Accepted, Controlled Acceptance, or Rejected
- Interactive station-level HVSR visualization
- Project-level statistical summaries
- PDF report generation
- GIS-compatible ESRI Shapefile export
- Google Earth KMZ export
- Project save/load functionality

## Requirements

- MATLAB R2026a
- Microsoft Windows 11 (64-bit)
- No additional MATLAB toolboxes required for routine operation
- Ghostscript is optional and is used to merge multi-page PDF reports

## Input Files

Each station requires paired Geopsy output files:

`station.hv`

`station.log`

An optional coordinate file can also be supplied in the following format:

X    Y    Z    Name

Example:

450123.55    4578123.21    105.3    m1

Coordinates are interpreted as WGS84 / UTM according to the UTM zone selected by the user.

## Example Data

The repository includes example Geopsy `.hv` and `.log` files that can be used to test the complete analysis workflow.

## Running the Software

Download or clone the repository and run:

HV_SESAME_ANALYZER_V1.m

from MATLAB.

## Quality Classification

The final classification is based on the combined SESAME reliability and clear-peak assessments:

- Accepted: Reliability = TRUE and Clear Peak = TRUE
- Controlled Acceptance: only one criterion group is fully satisfied
- Rejected: neither criterion group is fully satisfied

## Outputs

HV-SESAME Analyzer can generate:

- PDF project reports
- KMZ files for Google Earth
- ESRI Shapefiles
- HSAP project files
